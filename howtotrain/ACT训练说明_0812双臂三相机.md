# ACT / ACT-DINOv3 训练说明：0812 双臂三相机

本文给出可复用的 0812 训练流程。通过替换 `DATA_ROOT`、`STATS_ROOT`、`OUTPUT_ROOT` 和 `GPU`，可用于 continuous、binary 以及同结构 subtask 数据集。远端服务器为：

```bash
ssh -p 50210 wengyikun@183.230.224.121
```

训练镜像为 `lerobot-pi05-train:20260706`。每个容器只暴露一张 GPU，禁止使用 `--gpus all`。

## 1. 数据合同

当前推荐的 binary 数据集：

```text
/data/wengyikun/datasets/joint_songling/0812_binary_gripper_without_ep173_174
202 episodes / 125558 frames / 26 FPS
```

它由 continuous 数据集转换得到：

```text
source: /data/wengyikun/datasets/joint_songling/0812_closed_gripper_zero_without_ep173_174
gripper <= 0.06 m -> 0.0
gripper > 0.06 m  -> 0.1
```

`binary_gripper_summary.json` 必须满足：

```json
{
  "mode": "binary",
  "state_gripper_indices": [9, 19],
  "action_gripper_indices": [6, 13]
}
```

如果使用 TurboVLA overlay，`overlay_contract.json` 必须写：

```json
"gripper_mode": "binary"
```

不能继续使用 `continuous_absolute_closed_zero`。该字段不会改变 parquet 数值，但必须与实际数据语义一致。

## 2. state/action 语义

20D state：

```text
左关节 [0:6]       q[t] - q[t-1]
左 endpoint xyz     [6:9] 绝对
左夹爪               [9]   绝对 binary
右关节 [10:16]     q[t] - q[t-1]
右 endpoint xyz     [16:19] 绝对
右夹爪               [19]   绝对 binary
```

14D action：

```text
左关节 [0:6]       q[t+k] - q[t]
左夹爪               [6]    绝对 binary
右关节 [7:13]      q[t+k] - q[t]
右夹爪               [13]   绝对 binary
```

统一配置：

```text
joint_representation=relative
state_absolute_indices=[6,7,8,9,16,17,18,19]
state_gripper_indices=[9,19]
gripper_indices=[6,13]
condition_on_state=true
chunk_size=16
n_action_steps=16
```

处理顺序为：原始数据 -> 相对转换 -> q01/q99 归一化 -> 模型 loss。推理时先反归一化，再把相对关节量加回当前绝对关节状态。

## 3. 图像处理

相机顺序固定为：

```text
top -> gripper_left -> gripper_right
```

输入尺寸：

```text
top:           405x720 -> 上补157/下补158黑边 -> 720x720 -> 224x224
gripper_left:  480x640 -> 中心裁剪480x480 -> 224x224
gripper_right: 480x640 -> 中心裁剪480x480 -> 224x224
```

`dataset.image_transforms.enable=false` 只关闭随机增强，不关闭确定性的补边、裁剪和 resize。

## 4. q01/q99

每个数据集必须重新计算 state/action 统计，不能复用 source 数据集或 subtask 的统计。

当前 binary chunk16 统计：

```text
/data/wengyikun/act_stats/0812_binary_gripper_without_ep173_174_relative_endpoint_absolute_chunk16_only
```

目录必须包含：

```text
relative_state_q01_q99.json             20D
relative_action_chunk16_q01_q99.json    14D
relative_stats_manifest.json            horizons=[16]
```

通用计算方式：

```bash
export DATA_ROOT=/data/wengyikun/datasets/joint_songling/<dataset_name>
export STATS_ROOT=/data/wengyikun/act_stats/<dataset_name>_relative_endpoint_absolute_chunk16

docker run --rm -i --ipc=host \
  -e PYTHONPATH=/home/wengyikun/lerobot/src \
  -v /data/wengyikun:/data/wengyikun \
  -v /home/wengyikun/lerobot:/home/wengyikun/lerobot \
  -w /home/wengyikun/lerobot lerobot-pi05-train:20260706 \
  python3 -m lerobot.scripts.compute_full_dataset_relative_joint_stats \
  --dataset-root="$DATA_ROOT" \
  --output-dir="$STATS_ROOT" \
  --horizons='[16]' \
  --gripper-indices='[6,13]' \
  --state-absolute-indices='[6,7,8,9,16,17,18,19]'
```

启动前检查 manifest：

```bash
python3 - "$DATA_ROOT" "$STATS_ROOT" <<'PY'
import json, sys
from pathlib import Path
data, stats = map(Path, sys.argv[1:])
info = json.loads((data / "meta/info.json").read_text())
manifest = json.loads((stats / "relative_stats_manifest.json").read_text())
assert tuple(info["features"]["observation.state"]["shape"]) == (20,)
assert tuple(info["features"]["action"]["shape"]) == (14,)
assert manifest["source_dataset_root"] == str(data.resolve())
assert manifest["horizons"] == [16]
assert manifest["state_absolute_indices"] == [6,7,8,9,16,17,18,19]
assert manifest["state_gripper_indices"] == [9,19]
assert manifest["gripper_indices"] == [6,13]
print("DATA_AND_STATS_OK")
PY
```

## 7. ACT-DINOv3 启动差异

ACT-DINOv3 使用：

```text
policy.type=act_dinov3
代码目录=/home/wengyikun/act_dinov3_worktree
DINOv3=/data/wengyikun/models/turbovla_joint_songling/dinov3-vitl16-pretrain-lvd1689m
主网络 lr=1e-5
DINOv3 lr=1e-6
dinov3_gradient_checkpointing=true
dinov3_autocast_dtype=bfloat16
```

除视觉 backbone 和 DINOv3 专用学习率外，数据集、相对 state/action、q01/q99、chunk、优化器、scheduler 和保存周期必须与标准 ACT 对齐。

GPU5 当前正式输出目录：

```text
/data/wengyikun/outputs/act_dinov3_0812_binary_gripper_without_ep173_174_relative_three_rgb_chunk16_b64_500k_gpu5_20260814_pyav1/train_out
```

DINOv3 worktree 的 `video_utils.py` 必须包含：

```python
value = os.environ.get("LEROBOT_PYAV_DECODE_THREADS")
stream.codec_context.thread_count = int(value)
```

仅设置环境变量但代码不读取它，不会限制 PyAV 线程。启动后检查：

```bash
docker exec "$CONTAINER_NAME" bash -lc \
  'grep -n "codec_context.thread_count" /home/wengyikun/act_dinov3_worktree/src/lerobot/datasets/video_utils.py; echo "$LEROBOT_PYAV_DECODE_THREADS"'
```

GPU5 batch64 显存约为 `23.4/24.6 GB`，接近 4090 上限。发生 OOM 时优先把 batch 调为 32，不要关闭 q01/q99 或改变动作语义。

## 8. 检查训练

```bash
docker ps --format 'table {{.Names}}\t{{.Status}}'
docker logs --tail 100 "$CONTAINER_NAME"
nvidia-smi --query-gpu=index,memory.used,memory.total,utilization.gpu --format=csv,noheader,nounits
```

正常日志必须出现：

```text
dataset preflight 或 DINOV3_*_PREFLIGHT_OK
Effective batch size: 64 x 1 x 1 = 64
Start offline training
step=10 train/loss=<finite value>
```

错误标准：`Traceback`、`CUDA out of memory`、`nan`、`inf`、stats source mismatch。

## 9. 停止和恢复

只停止指定训练：

```bash
docker stop -t 30 "$CONTAINER_NAME"
```

恢复训练前必须同时确认：

```text
checkpoint 所属数据集
state/action 表示
q01/q99 source_dataset_root
chunk_size
optimizer/scheduler state
```

真正续训必须使用 `--resume=true` 并恢复 optimizer/scheduler。只加载模型权重但从 step0 开始属于 warm-start，不是续训。
